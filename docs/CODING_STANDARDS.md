# Coding Standards

## Tests

- Factory
- RefreshDatabase
- AAA
- Descriptive test names

## Controllers

No business logic.
Never use DB facade directly inside Controllers.
Prefer constructor property promotion.

## Services

Business logic only.

## Models

Relationships

Scopes

Accessors

Mutators

## Commits

One feature = one commit.

## Comments

Explain WHY.

Not WHAT.
